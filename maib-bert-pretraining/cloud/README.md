|---|---|---|
| GPU | Tesla T4 با ۱۶ گیگ حافظه، حدود ۳ برابر سریع‌تر از GTX 1650 Ti | Tesla T4 |
| سهمیه | **۳۰ ساعت GPU در هفته**؛ هر جلسه حداکثر ۱۲ ساعت | نامشخص و متغیر؛ معمولاً چند ساعت در روز |

| پیش‌نیاز | تأیید شماره‌ی تلفن (برای فعال شدن GPU و اینترنت) | حساب Google |

**هشدار صادقانه برای کاربران ایران:**
- هر دو سرویس متعلق به Google هستند و ممکن است IP ایران را مسدود کنند. در این صورت به ابزار عبور از تحریم نیاز دارید.
- Kaggle برای تأیید تلفن ممکن است شماره‌ی ایران را قبول نکند.
- **اول ثبت‌نام و تأیید را امتحان کنید**، بعد فایل‌ها را آماده کنید.

کد پروژه بدون هیچ تغییری روی هر دو سرویس اجرا می‌شود. Kaggle و Colab از قبل PyTorch و transformers را دارند، پس نصب لازم نیست.

## قدم ۱: آماده‌سازی فایل روی لپ‌تاپ (برای هر دو سرویس)

corpus تمیزشده (`corpus/`) باید **یک بار روی لپ‌تاپ ساخته شده باشد**. اگر DAPT را قبلاً اجرا کرده‌اید، ساخته شده است. بعد:

```bash
cd ~/Mohammad/arshad/paper/AI-Paper/maib-bert-pretraining
python archive_previous_run.py light --yes     # اگر هنوز نتایج اجرای سبک را کنار نگذاشته‌اید
bash cloud/make_upload_zip.sh --no-models      # می‌سازد: ../maib-work.zip
```

**چه چیزهایی در zip هست:**
- کد
- `data/` (تقسیم مقاله)
- `corpus/` (متن‌های تمیزشده، چند ده مگابایت)
- `reports/`
- `results/` (نتایج BERT اصلی از مقاله)

**چه چیزهایی نیست:**
- `.venv`
- PDFها (حدود ۱.۵ گیگ؛ وقتی `corpus/` ساخته شده باشد، دیگر لازم نیستند)

پس فایل کوچک است و آپلودش سریع است. pipeline هم با دیدن `corpus/`، دانلود و ساخت corpus را رد می‌کند.

اگر روی لپ‌تاپ مدلی را تمام کرده‌اید و می‌خواهید ادامه‌اش در فضای ابری انجام شود، `--no-models` را نگذارید. فایل بزرگ‌تر می‌شود: هر مدل حدود ۴۴۰ مگابایت.

## قدم ۲-الف: Kaggle

**یک بار:**
1. در https://www.kaggle.com ثبت‌نام کنید.
2. Settings → **Phone verification** را انجام دهید. بدون این کار، GPU و اینترنت فعال نمی‌شوند.
3. **Datasets → New Dataset**: فایل `maib-work.zip` را آپلود کنید. نام آن را `maib-work` بگذارید و Private بماند.
4. **Code → New Notebook**: از منوی File → **Import Notebook** فایل `cloud/kaggle_notebook.ipynb` را باز کنید.
5. در پنل سمت راست notebook:
   - **Session options → Accelerator → GPU T4 x2**. P100 را انتخاب نکنید؛ نسخه‌های جدید PyTorch روی آن کار نمی‌کنند.
   - **Internet → On**. لازم است تا `bert-base-uncased` دانلود شود.
   - **Input → Add Input**: دیتاست `maib-work` را اضافه کنید.

**هر جلسه (حدود ۱۰.۵ ساعت کار):**
6. بالای صفحه **Save Version → Save & Run All (Commit) → Save** را بزنید.
   - اجرا در پس‌زمینه انجام می‌شود و **می‌توانید مرورگر را ببندید**.
   - پیشرفت را در صفحه‌ی notebook، زیر Versions → Logs ببینید.
7. notebook بعد از ۱۰.۵ ساعت خودش با خیال راحت متوقف می‌شود. همه‌ی فایل‌ها، از جمله checkpoint نیمه‌کاره، در **Output** همان نسخه ذخیره می‌شوند.

**جلسه‌ی بعد (ادامه‌ی کار):**
8. notebook را باز کنید (Edit). در **Input → Add Input → Your Work → Notebooks**، **خروجی همین notebook** را اضافه کنید.
9. دوباره **Save & Run All (Commit)** را بزنید.
   - سلول اول از میان ورودی‌ها خودکار نسخه‌ای را برمی‌دارد که بیشترین پیشرفت را دارد.
   - آموزش از آخرین epoch تمام‌شده ادامه پیدا می‌کند.
10. این کار را تکرار کنید تا در لاگ پیام `Done in ... h` را ببینید. نتیجه در Output است: `maib-bert-pretraining/reports/comparison.md`.

**گرفتن نتیجه روی لپ‌تاپ:** در صفحه‌ی notebook، تب **Output → Download** را بزنید. فقط پوشه‌های `results/` و `reports/` را در پروژه‌ی لپ‌تاپ کپی کنید و `python step6_compare.py` را اجرا کنید.

**بودجه‌ی زمانی:** کل آزمایش روی T4 حدود ۱ تا ۱.۵ روز GPU طول می‌کشد. یعنی ۳ تا ۴ جلسه، و با سهمیه‌ی ۳۰ ساعت در هفته، حدود ۱ تا ۲ هفته.

## قدم ۲-ب: Google Colab

**یک بار:**
1. فایل `maib-work.zip` را در **ریشه‌ی My Drive** آپلود کنید.
2. در https://colab.research.google.com از File → Upload notebook فایل `cloud/colab_notebook.ipynb` را باز کنید.
3. **Runtime → Change runtime type → T4 GPU** را انتخاب کنید.

**هر جلسه:**
4. **Runtime → Run all** را بزنید.
   - سلول اول اجازه‌ی دسترسی به Drive را می‌پرسد.
   - سلول دوم فقط بار اول zip را در Drive باز می‌کند.
   - پروژه در Drive است، پس با قطع شدن Colab چیزی از دست نمی‌رود.
5. **تب را باز نگه دارید** و هر چند ساعت یک بار سر بزنید. Colab رایگان اگر شما را غیرفعال ببیند، یا وقتی به سقف سهمیه برسید، قطع می‌کند.
6. بعد از قطع شدن: دوباره **Run all** را بزنید. کار از آخرین epoch تمام‌شده ادامه پیدا می‌کند.

## نکته‌های مهم (برای هر دو)

- **تنظیمات `config.py` را وسط کار عوض نکنید.** checkpoint فقط با همان تنظیمات ادامه پیدا می‌کند.
- **هم‌زمان روی دو جا اجرا نکنید**، مثلاً لپ‌تاپ و Kaggle با هم. در این حالت دو نسخه‌ی متفاوت از پیشرفت کار خواهید داشت.
- نتایج روی T4 و GTX 1650 Ti به دلیل محاسبات GPU **ممکن است در رقم‌های آخر کمی فرق کنند**. این طبیعی است و نتیجه‌گیری را عوض نمی‌کند. در پایان‌نامه بنویسید هر مرحله روی چه GPUای اجرا شده است. این اطلاعات در فایل‌های `results/*.json` و `reports/pretrain_*.json` ثبت می‌شود.
- اگر سلول GPU خطا داد: Accelerator یا Runtime را دوباره چک کنید. ممکن است سهمیه‌ی GPU تمام شده باشد؛ Kaggle میزان مصرف را در پروفایل شما نشان می‌دهد.
